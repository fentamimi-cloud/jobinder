## 🗄️ **Database Schema Details**

### **jobs Table (28 columns)**

**Key Fields:**
- `id` (UUID) - Primary key
- `employer_id` (TEXT) - References users.id
- `title`, `description`, `requirements`, `responsibilities`
- `job_type` - full_time, part_time, contract, internship, freelance
- `experience_level` - entry, mid, senior, executive
- `required_skills` (TEXT[]) - Array of skill names
- `salary_min`, `salary_max`, `salary_currency`
- `status` - draft, active, paused, closed, filled
- `matches_count`, `applications_count`, `views_count`

**Constraints:**
- ✅ CHECK constraints on enums (job_type, experience_level, status)
- ✅ Foreign key cascade delete (if employer deleted, jobs deleted)
- ✅ Default values for analytics counters
- ✅ JSONB for flexible settings

### **job_matches Table (23 columns)**

**Key Fields:**
- `id` (UUID) - Primary key
- `job_id` (UUID) - References jobs.id
- `job_seeker_id` (TEXT) - References users.id
- `match_score` (DECIMAL) - 0-100 score
- `match_breakdown` (JSONB) - Detailed scoring
- `employer_status` - pending, interested, rejected, contacted, etc.
- `job_seeker_status` - pending, interested, applied, etc.
- `employer_swiped_right`, `job_seeker_swiped_right`
- `is_mutual_match` (BOOLEAN) - Auto-set by trigger
- `employer_notes` (TEXT) - Private notes

**Smart Features:**
- ✅ Auto-detect mutual matches (trigger)
- ✅ Track swipe history
- ✅ Employer private notes
- ✅ Unique constraint (one match per job-seeker pair)

### **job_applications Table (12 columns)**

**Key Fields:**
- `id` (UUID) - Primary key
- `job_id`, `job_seeker_id`, `match_id`
- `cover_letter` (TEXT)
- `custom_resume_url` (TEXT) - Override profile resume
- `answers` (JSONB) - Custom screening questions
- `status` - submitted, reviewed, shortlisted, interview, etc.
- `rejection_reason`, `employer_feedback`

```sql
SELECT * FROM get_top_candidates(
  'b16c0875-6688-4dca-96ce-fda2a5433978',  -- job_id
  10,                                        -- limit
  50.0                                       -- min_score
);
```

### **Get Employer's Mutual Matches:**
```sql

```

### **Calculate Job Completion:**
```sql
SELECT 
  title,
  calculate_job_completion(id) as completion
FROM jobs;
```
